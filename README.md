# Boombox

Нативный Android-клиент для [Navidrome](https://www.navidrome.org/): библиотека по исполнителям, альбомам и жанрам, поиск, фоновое скачивание и менеджер офлайн-музыки.

## Возможности

- Вход на любой Navidrome-сервер (Subsonic / OpenSubsonic API). Сессия запоминается.
- Библиотека: исполнители, альбомы и жанры.
- Поиск по исполнителям, альбомам, трекам и жанрам.
- Выбор папки для загрузок (системный проводник).
- Структура папок настраивается (по умолчанию `Исполнитель / альбом`). Можно сортировать по жанрам и менять шаблон имени файла.
- Скачивание альбома, трека или всей дискографии исполнителя.
- Фоновые загрузки с уведомлением о ходе (уведомления можно выключить).
- Импорт уже существующих файлов в папке после переустановки.
- Менеджер скачанного: удалить трек, альбом или всего исполнителя.
- Мини-плеер можно выключить в настройках или смахнуть — музыка останавливается.
- Проигрывание с сервера и из офлайна.
- Material 3, тёмная тема.

## Установка APK

1. Откройте [Releases](https://github.com/Nasty1028339219182/boombox/releases).
2. Скачайте `app-release.apk` из **Boombox 1.1.0**.
3. На телефоне разрешите установку из неизвестных источников и откройте файл.

Демо-сервер: `https://demo.navidrome.org`, логин и пароль `demo`.

## Сборка

Нужны JDK 17 и Android SDK (compileSdk 35).

```bash
cd android
./gradlew assembleRelease
```

APK: `android/app/build/outputs/apk/release/app-release.apk`.
